# 真机验收清单

此清单是待执行的真机验证计划，不代表已通过。建议覆盖 Android 8、13、14、15 及至少一种国产 ROM。

- 首次启动，无权限也能使用计时台、记录、编辑、导出。
- 名称为空、时长为 0 或超过 3600 秒不能保存；最多 8 个计时器，至少保留 1 个。
- 开始、暂停、继续、重置正常；编辑会重置该计时器；同一时刻主界面与悬浮窗显示一致。
- 退出到桌面，打开悬浮窗后计时继续；跨越完成时间后显示 00:00，震动只发生一次。
- 拒绝通知权限仍可开启悬浮窗；前台服务可从系统“活动应用”管理中停止。
- 拒绝悬浮窗权限可返回应用；授权后再点开启；使用过程中撤销权限不会崩溃。
- 拖动、收起、展开、滚动 8 个计时器、横竖屏切换、小屏幕、放大字体均可操作；窗口不会跑出屏幕。
- 悬浮窗关闭按钮和通知关闭按钮均能停止服务；再次开启不会出现多个窗口。
- 应用被系统结束后重新进入：同一次开机中的计时按剩余时间恢复；手机重启后原运行中计时回到初始时长。
- 关闭悬浮窗、锁屏或系统结束进程后，允许完成提醒延迟；不应对外宣传为精确闹钟。
- 新增求生者／监管者、胜／平／负记录，编辑后数量不变，删除需确认；满 200 条时提示先导出和删除。
- 中文、引号、逗号、换行笔记的 CSV 在表格工具中正确显示，公式前缀按文本导出。
- 导出取消、导出时旋转屏幕、不可写文档位置可正常处理；无需整个存储目录访问权限。
- 应用无联网、无障碍、录屏、存储读取权限；没有游戏账号登录入口。
